## [1.0.0] — 2026-07-08

### Added
- Lightweight Flutter app for submitting and tracking LUXO Place service requests.
- Multi-screen layout: Request, History, History Detail, Settings, Setup, and embedded web view.
- Local data persistence with `shared_preferences`.
- Provider-based state management (`UserProvider`, `HistoryProvider`).
- First-run setup screen to configure user profile on initial launch.
- Embedded web view via `flutter_inappwebview` for in-app portal access.
- LUXO Place gold-and-dark brand theme applied throughout.
- Cross-platform support: Android, iOS, web, Windows, macOS, Linux.
